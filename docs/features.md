# Keel features

Everything Keel does, with links to the reference for each part. New to Keel? Start with the [getting-started guide](getting-started.md).

## Feature list

- **Dual pane and tabs**: two panes (Ctrl+Shift+D for one), any number of tabs per pane (drag to reorder), back/forward history, breadcrumb or editable path (Ctrl+L), details and grid views with thumbnails, a Finder-style sidebar with your own Favorites, drives (eject for removable ones), hosts, clouds, devices, the library and its tags.
- **Search**: each pane's **Search here** box searches under its folder (subfolders too) in a tab next to it, and Esc goes back (local folders and remote hosts); Ctrl+F opens a search tab over everything. Windows uses [Everything](https://www.voidtools.com/) when it is running and otherwise Keel's own index (see [Search without Everything](files.md#search-without-everything)), macOS uses Spotlight (`mdfind`), Linux uses `plocate`/`locate` when installed, otherwise a folder walk. Ctrl+Enter opens a result's folder with the file selected.
- **Fuzzy finder**: Ctrl+P matches against every folder the search index knows (or a walk of your home folder), the files in and below the current folder, and the library's files; Enter on a file opens its folder with the file selected and previewed.
- **Command palette**: Ctrl+Shift+P lists every action by name with its shortcut.
- **Configurable keys**: Settings → Keyboard binds any command to any number of keys (record, remove, reset, conflict warnings, import and export), per profile. See [Changing the keys](files.md#changing-the-keys).
- **Filter by typing**: start typing in a list to filter it; Esc clears.
- **Previews**: F3 shows or hides the preview panel (there is no Ctrl+Shift+V shortcut). Code with syntax highlighting, text, Markdown, images (PNG, JPEG, GIF, WebP, BMP, ICO, SVG), PDF pages (needs the pdfium library next to the binary: included in the release archives, or run `scripts/fetch-deps`), CSV/TSV and spreadsheets (xlsx, xls, xlsb; an xls over 32 MiB, or one claiming more cells than a sheet holds, is not previewed), Word documents (docx, with headings, lists, tables and page breaks), PowerPoint slide text (pptx), OpenDocument text, spreadsheets and presentations (odt, ods, odp), HEIC, HEIF and AVIF photos (needs `ffmpeg` 7 or newer on `PATH`), camera RAW files by their embedded preview (DNG, CR2, NEF, ARW, ORF, RW2, PEF; not CR3 or RAF), fonts (ttf, otf, ttc: a sample sentence with the family and style; not woff), video thumbnails and audio files with their tags, cover, waveform and Play/Pause (both need `ffmpeg` on `PATH`), hex for anything else.
- **Hover previews**: rest the pointer on a file in any view for half a second and a large preview floats next to it (up to 40 % of the window each way, kept inside it): photos, PDF pages, video frames, audio covers, font samples and the first 30 lines of text and Markdown, from the preview panel's cache. Moving off, scrolling, a key or a click hides it. Settings → General → **Hover preview** turns it off or sets the delay (200 to 2000 ms).
- **Quick Look, path bar, Go to Folder**: Space opens a floating preview of the selection that follows the arrow keys, with an index sheet for several items, full screen and Open With…; a path bar at the bottom of the window takes drops (move, Alt copies) and right-click Copy as Pathname; a drag resting on a folder opens it (spring-loaded folders); Ctrl+Shift+G goes to a typed path with completion. See [Quick Look](files.md#quick-look), [Path bar and status bar](files.md#path-bar-and-status-bar), [Spring-loaded folders](files.md#spring-loaded-folders) and [Go to Folder](files.md#go-to-folder).
- **Inspector**: Ctrl+I turns the preview panel into an inspector of the selected item: its source, volume, content id, first seen and last hashed, protection count, every other copy (click to open it), the operations that touched it (copied, moved, renamed, deleted, tagged), its tags, and a folder's totals. See [Inspector](files.md#inspector).
- **File operations**: copy, move, rename (F2; Ctrl+F2 renames many at once), new folder/file, and delete to the OS trash (never a permanent delete), with progress, cancel, and skip/overwrite/rename prompts on name clashes. Drag and drop between panes and from other apps. **Undo** (Ctrl+Z, or the toast's Undo button) reverses the last 20 operations one by one, after checking nothing changed since and never overwriting; see [Copy, move and delete](getting-started.md#copy-move-and-delete). **Folder operations** (merge folders, flatten, organize by type, year or month, attributes, links, remove empty folders, folder dates set to the newest change below) preview every move before they run and are undone with Ctrl+Z; see [Folder operations](files.md#folder-operations). **Compress (NTFS)** (Windows: LZNT1 and the Overlay Filter's XPRESS and LZX, with the saving measured) and your own **cleanups** (commands with placeholders, run on the selection); see [Compress (NTFS)](files.md#compress-ntfs) and [Cleanups](files.md#cleanups).
- **System clipboard**: Ctrl+C / Ctrl+X / Ctrl+V exchange files with Explorer and with Linux file managers, cut included (on Linux through X11, or XWayland in a Wayland session: GNOME Files, Nemo, Caja, Thunar and PCManFM read `x-special/gnome-copied-files`, Dolphin `application/x-kde-cutselection`, and a cut made in those apps pastes in Keel as a move), and with Finder (copy; Finder has no cut on the clipboard, so a cut made in Keel is a move only when pasted in Keel).
- **Recycle Bin / Trash**: the sidebar's Recycle Bin (Windows) or Trash (macOS, Linux) entry opens your bin as a folder showing when each item was deleted and, on Windows and Linux, where it came from. Right-click to Restore (macOS: Restore to…), Delete permanently or Empty; both deletes ask first. See [Recycle Bin and Trash](files.md#recycle-bin-and-trash).
- **Archives as folders**: zip, 7z, tar (gz, bz2, xz, zst) and rar open like directories, nested ones too; entries of a zip can be deleted, renamed, moved and added. See [Archives](files.md#archives).
- **Embedded terminal**: a shell pane under the file panes that follows the active folder. See [Terminal](files.md#terminal).
- **Recover deleted files**: `keel recover scan E:` lists the deleted files an NTFS, exFAT or FAT drive (or a volume image) still holds, with how likely each is intact, and `keel recover restore <id> --to <folder>` brings them back to another drive; it needs administrator rights and never writes to the drive it recovers from. See [Recovering deleted files](files.md#recovering-deleted-files).
- **WSL**: each installed WSL distribution's files in the sidebar (Windows), opened like a network share with a permanent-delete prompt (there is no Recycle Bin there), and `keel <folder>` typed inside a distribution opens it in the Windows window. See [WSL](wsl.md).
- **SFTP remotes**: browse, preview and copy to and from any SSH host. See [Remotes over SSH](remotes.md#remotes-over-ssh).
- **FTP and FTPS remotes**: NAS boxes, web hosts and cameras, browsed and copied to and from like SFTP hosts; FTPS checks the server's certificate (and pins one you trust), plain FTP is marked as unencrypted wherever it shows. No mounts or library sources on FTP. See [FTP and FTPS](remotes.md#ftp-and-ftps).
- **Cloud accounts** (Google Drive, Dropbox, S3-compatible buckets, WebDAV) as folders; Drive and Dropbox sign in with your own OAuth client id, S3 and WebDAV with keys or a password; all secrets stay in the OS keychain; storage quota (Drive, Dropbox) and Copy link. See [Cloud accounts](../README.md#cloud-accounts-bring-your-own-client-id).
- **Columns view**: Miller columns per pane, plus a **drop zone** strip that carries files across navigation. See [Columns view and drop zone](files.md#columns-view-and-drop-zone).
- **Folder sizes and a Sizes view**: folders show their total size (kept with the library index, or walked on request with **Calculate sizes**), sort by it, and the Sizes view shows what fills a folder or a drive with share bars; `keel du` from a terminal. See [Folder sizes and the Sizes view](files.md#folder-sizes-and-the-sizes-view).
- **Disk Usage window** (Ctrl+Shift+U, or a drive's right-click menu): scans drives and folders in parallel and shows them as WinDirStat does, a directory tree with subtree bars and every column (size on disk, items, last change, attributes, owner…), and a file types list with your system's type names; one selection across both. See [The Disk Usage window](files.md#the-disk-usage-window).
- **Profiles**: separate settings and sessions you can switch at runtime. See [Profiles](files.md#profiles).
- **Named sessions**: the palette's "Save session as…" keeps the open tabs and views under a name; "Open session: <name>" brings them back, "Delete session: <name>" removes one. Each profile has its own. See [Profiles](files.md#profiles).
- **Icon themes**: install VS Code icon themes from the Marketplace. See [Icon themes](files.md#icon-themes).
- **Folder colors and icons**: right-click a folder in a library source for a color (a tint and a dot) or an emoji or icon-theme icon, shown in every view, the sidebar and Ctrl+P, and synced to your other devices; a file can take an emoji or icon-theme icon the same way. See [Folder colors and icons](files.md#folder-colors-and-icons).
- **Get Info**: Finder-style info windows (several at once, or one that follows the selection with Ctrl+Alt+I) with General, More Info, Name & Extension, Comments, Open with, Preview and Sharing & Permissions sections, for files, folders, drives and several items. See [Get Info](files.md#get-info).
- **Finder tag colors**: tags in Finder's eight colors shown as dots after file names, a row of color dots in the context menu, and on macOS two-way sync with Finder's own tags. See [Tags and Finder colors](files.md#tags-and-finder-colors).
- **Command line, single instance and global hotkeys**: `keel <folder>` opens in the running window; Ctrl+Shift+Alt+K brings Keel forward, and optional hotkeys open a new window or toggle Keel. See [Command line](files.md#command-line).
- **Drag out** of Keel onto other apps: Windows, macOS, and Linux on X11 (or XWayland); see [Dragging files to other apps](files.md#dragging-files-to-other-apps).
- **Windows shell menu**: **More options** in the right-click menu, Shift+right-click or Shift+F10 opens Explorer's menu for local files (installed handlers, Send to, Open with, Share), and its commands are searchable in the command palette as `Shell: …`. Keel's own Delete, Rename, Cut, Copy, Paste and Properties replace Explorer's. See [Windows shell menu](files.md#windows-shell-menu).
- **Own search index** on Windows, so search works without Everything. See [Search without Everything](files.md#search-without-everything).
- **Library**: an index of every file across your folders, drives, SSH hosts and cloud accounts that keeps working when a drive is unplugged. Cross-source search with filter chips (kind, type, tag, source, size, modified, favorites, contents) or a query syntax, over names and the text inside documents (text, PDF, Word, Excel, PowerPoint, OpenDocument; a snippet under each such result), tags (with a tag assign mode: Ctrl+Shift+A, then number keys toggle tags on the selection), favorites, hand-ordered collections across sources (reorder by dragging), saved views, a duplicate finder, and a preview before every copy, move or delete. See [Library](library.md#library).
- **Freezes**: keep a source's index as it is now, then browse that dated state read-only like an offline source, and delete it when done; only rows that change afterwards are copied. See [Freezes](library.md#freezes).
- **Media view**: a photo and video grid that scrolls 129,000 items smoothly, video scrubbing on hover, date headers, and a full-window viewer with zoom, an info panel and video playback with sound. See [Media view](library.md#media-view).
- **Library backup and restore**: one file holds the library's index, tags, favorites and content ids; restore it as a new library on this or another machine, from the palette or `keel library backup` / `restore`. See [Backup and restore](library.md#backup-and-restore).
- **Protection**: how many copies of each file exist and on how many physical disks or accounts, backup state, integrity checks and a drive inventory, with "last copy" warnings before a delete. See [Protection](library.md#protection).
- **Devices and Spacedrop**: pair your own machines with a short code or QR code, browse their shared folders as `node://` sources, send files with resumable, verified Spacedrop, and keep tags and favorites in sync between them. See [Devices and Spacedrop](devices.md#devices-and-spacedrop).
- **Daemon, CLI and MCP**: `keel-daemon` serves the library over JSON-RPC, `keel search`, `keel plan` and friends work from a terminal (`keel op <name>` runs any operation, preview first, and [an agent skill](agent-skill.md) teaches agents to use it), and `keel mcp` lets Claude Code, Codex and other agents use the library with a preview before every change. The window attaches to a running daemon, so all of them share one library while it is open. See [Daemon, CLI and MCP](daemon.md#daemon-cli-and-mcp).
- **Generated API clients**: TypeScript and Swift parameter/result types and JSON-RPC methods from the Rust operation registry, with drift tests; mutating calls return previews. See [TypeScript](api.md#generated-typescript-client) and [Swift](api.md#generated-swift-client).
- **Open, open with, reveal** in the system file manager, open a terminal in the current folder.
- **Appearance**: a **Finder-style** look (Finder's spacing, corners and type; the Finder colors on the dark and light themes; the system accent color) or the **Classic** look, and an accent color of your own. See [Appearance](files.md#appearance).
- **Themes**: six built-in color themes (dark, light, Midnight, Paper, Dusk, High contrast), your own TOML files in `<config>/themes/`, and VS Code color themes installed from the Marketplace, mapped onto Keel's colours and adjusted for contrast where needed. One built-in file icon theme. See [Color themes](files.md#color-themes).
- **Interface language**: English or Spanish, picked in Settings → General → Language and applied at once; the panes' chrome, sidebar, status bar, context menu, command palette and Settings → General so far. See [Interface language](files.md#interface-language).
- **Settings** (Ctrl+,): theme, language, hidden files, dual pane, preview panel, maximum preview size. Open tabs are restored on the next start; a local folder that was deleted falls back to your home folder, while a tab on an unreachable network share stays open and shows the error. A `config.toml` or `session.json` that cannot be read is kept as `config.toml.bad` / `session.json.bad`.
- **Crash safety and reports**: a bug inside the UI resets the panes and Keel keeps running. A crash of the window or of keel-daemon writes a report to `crashes/` in the data folder (version, system, where it happened, a backtrace and the last 50 log lines; your user name, home folder, server names and e-mail addresses are removed, but file and folder names can appear, so read it before you post it), and the next start offers to show it, copy it or open a GitHub issue. Keel sends nothing. See [Crashes and bug reports](../README.md#crashes-and-bug-reports).

Settings live in `%APPDATA%\Keel` (Windows), `~/Library/Application Support/Keel` (macOS) or `~/.config/keel` (Linux); the session in `%LOCALAPPDATA%\Keel`, `~/Library/Caches/Keel` or `~/.cache/keel`; crash reports in `crashes/` in the data folder (`%LOCALAPPDATA%\Keel`, `~/Library/Application Support/Keel` or `~/.local/share/keel`; `KEEL_DATA_DIR` moves it). Set `KEEL_CONFIG_DIR` to keep settings and session in one folder instead (the window size and position that eframe saves in `app.ron` then go to its `window` folder). **Portable mode**: a file named `keel.portable` beside `keel.exe` keeps every setting, library, cache and index in a folder beside it ([Portable mode](files.md#portable-mode)).
