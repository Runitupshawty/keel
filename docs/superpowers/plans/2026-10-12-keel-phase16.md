# Keel Phase 16 Implementation Plan: Everything parity, search UI, file lists, servers and automation

> **For agentic workers:** same rules as earlier plan headers. Read [the audit](2026-10-12-everything-windirstat-audit.md) Part 1 (UI and options areas, File lists, Remote, Automation) and Part 3 first. Phase 15's `keel-query` and full-metadata index are the base; tasks here that need them say so, the others can start at once. Each task gets its own worktree. Run `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings` and the tests of the crates touched before every commit. New parsers of outside bytes (EFU, CSV, ETP commands, HTTP query strings) get fuzz targets. Every user-visible change goes into the docs and the CHANGELOG in the same task. Public repo: no hostnames, IPs, user names, personal names or personal paths anywhere.

**Goal:** Every part of Everything a user touches outside the query language: the search window's toggles and options, filters, bookmarks, history, columns, sorting, omissions, tray and hotkeys, configurable keys, localization, file lists, the HTTP and ETP servers, network indexes, `es`-compatible command line, Everything's window command line options, an SDK, and a URL protocol. Built in the Finder style of Phase 14 where it has landed.

**Live checks.** As Phase 15. Servers are tested on loopback only, and from the owner's second machine over the LAN only with the owner present.

**Review focus:**
1. Servers are off by default, bind to loopback by default, need a token or password, offer TLS, are read-only unless downloads are switched on, and a non-loopback bind without TLS shows an "unencrypted" warning the user must accept (Everything's ETP/HTTP have neither TLS nor more than Basic auth; Keel must be safer, not equal).
2. Nothing in history, bookmarks, run history or file lists leaves the machine except through a server the user turned on; **Do not save search history** and **clear history** work.
3. Configurable keys never allow a binding that makes an action unreachable (conflicts shown, reset per command).
4. File list import is bounded (rows, line length) and never follows paths it lists.
5. The SDK and URL protocol cannot run a file or change anything; they search and return results only.

### Task 76: the search window (worktree `task76`; needs Task 71)

**Read:** `crates/keel-app/src/search_tab.rs`, `worker.rs`, `chip_row.rs`, `view_details.rs`, `keys.rs`, `palette.rs`, `hotkey.rs`, `settings.rs`, `library_ui.rs` (saved views); the audit Part 3 UI table and Planner facts.

**Design points:**
- **Toggles** in the search field and the Search menu, with Everything's shortcuts: Match Case (Ctrl+I), Match Whole Words (Ctrl+B), Match Path (Ctrl+U), Match Diacritics (Ctrl+M), Regex (Ctrl+R), plus Match Prefix, Match Suffix, Ignore Punctuation, Ignore White-space; defaults per profile (Everything's Home tab).
- **Search options:** search as you type and its delay, select search on mouse click, focus search on activate, match whole filename when using wildcards, allow literal operators, replace forward slashes, operator precedence.
- **No 500 cap:** a virtualized result list that holds millions of rows (rows fetched by index from the engine's result set, sorted by the fast-sort permutations), "N objects" in the status bar with total size of results and of the selection.
- **Highlight** matched parts of names and paths (`no-highlight:` respected).
- **Columns:** a column chooser with every indexed and property column (Name, Path, Size, Size on disk, Extension, Type, Date modified/created/accessed/recently changed/run, Run count, Attributes, Folder size, File list filename, and any property from Task 73), column labels, column colors, column formulas (Everything 1.5), widths saved per filter/bookmark; secondary and tertiary sort, folders first (always, ascending, descending), sort mix, **sort date/size descending first**.
- **Filters:** built-ins Everything, Audio, Compressed, Document, Executable, Folder, Picture, Video; a filter editor (name, search, macro, match toggles, columns, sort, shortcut key); a **filter bar** (combo at the right of the search field) and a **Filters sidebar**; filters are `keel-query` macros.
- **Bookmarks:** a bookmark stores search, filter, sort, columns, index and match toggles; Organize Bookmarks dialog with folders, separators, shortcut keys; a **Bookmarks sidebar**; bookmarks merge with library saved views (create/edit/delete from the UI and new API ops `views.create`, `views.update`, `views.delete`, closing the audit's gap) and show as **Smart Folders** in the Phase 14 sidebar.
- **History:** search history with **always show suggestions** (dropdown under the field), sort by most recent or most used, complete-word on Ctrl+Space, **run history** (Task 73) with "select most run / last run result"; History settings (on/off, max entries, clear).
- **Folders sidebar** (Everything 1.5) narrowing results to a subtree.
- **Result omissions UI:** Omit results (Del in omission mode), Manage omissions, temporary omissions, toggle (Ctrl+Shift+O style), **search current results**.
- **Results options:** hide results when search is empty, clear selection on search, close window on execute, open path on double click in the path column, auto scroll, double-quote copy as path, do not select extension when renaming, full row select, single click open, underline titles, alternate row color, row mouseover, size format and standard, date format.
- **Context menu customization:** per item show / show with Shift / hide, custom open commands (Everything 1.5) with placeholders; copy name, copy full path, open path, open with, explore, properties, delete, rename (F2) all present (audit Part 3: most exist).
- **Keyboard:** every command bindable (replaces the const table in `keys.rs` with a profile keymap; conflict detection; reset), fixes the `parity.md` "configurable keys" overclaim.
- **Window behavior:** **Quick Search window** (Everything's main window shape: a small window with only the search field and results) on a global hotkey; hotkeys for New window, Show window, Toggle window; open searches in tabs or new windows, switch to new tabs immediately; **tray icon** (run in background, single-click tray, new window from tray); always on top; fullscreen; restore previous session; zoom/scale.
- **UI-state functions** (`columns:`, `add-columns:`, `remove-columns:`, `layout:`, `sort:`, `sort-ascending:`, `folders-first:`, `alternate-row-color:`, `on-top:`, `folders-sidebar:`, `bookmarks-sidebar:`, `filters-sidebar:`, `preview:`, `max-threads:`, `regular-expression-match0..9:` columns) apply when used in a search, filter or bookmark.
- **Settings:** an **Advanced settings** table (every setting, searchable, show only modified, value editor), **Import / Export / Reset settings**.
- **Localization** (parity gap #20): `fluent` message files, every string moved, English plus German, French, Spanish, Simplified Chinese, Japanese to start (machine-assisted, marked for review), language setting, right-to-left layout check with Arabic as a test locale.

**Tests:** each toggle's effect through the worker, a 3-million-row virtual list scrolls at 60 fps in the harness, bookmark round-trip, keymap conflicts, omissions, every string present in every locale (a test), walkthrough flow for filters and bookmarks.

**Commits:** `feat(app): search toggles and options`, `feat(app): virtual result list without a cap`, `feat(app): columns and sorting`, `feat(app): filters and bookmarks`, `feat(app): history and suggestions`, `feat(app): omissions and folders sidebar`, `feat(app): configurable keys`, `feat(app): quick search window, tray and hotkeys`, `feat(app): advanced settings, import and export`, `feat(app): localization`, `docs: the search window`

### Task 77: file lists (worktree `task77`; needs Task 70 for indexing them)

**Design points:**
- **EFU** read and write (`keel-filelist` module): UTF-8 CSV with header, `Filename` required, `Size`, `Date Modified`, `Date Created`, `Attributes` and any property column; FILETIME or ISO-8601 dates. Also open `.txt` (one path per line) and `.csv`. Fuzz target `efu`.
- **Open a file list** as a search tab (File → Open File List; double-click an `.efu`; EFU file association set by the installer, opt-in); search inside it with the whole language; `filelist:`, `filelist-filename:`, `filelist-full-path:` functions.
- **File List Editor:** new list, drag files and folders in, import and merge, remove duplicates, **Update** (rescan the listed folders), save.
- **Create file list** from a folder with include/exclude folder and file filters, no-subfolders, no-folders, no-files (`keel filelist create`, and the UI).
- **File lists in the index** (Settings → Search → File lists), monitored and reloaded on change.
- **Export results** (File → Export, or selection only): EFU, CSV, TSV, TXT, M3U, M3U8, JSON, with header and UTF-8 BOM options.
- **`.metadata.efu` sidecars** (Everything 1.5): a `.metadata.efu` in a folder supplies extra properties for its files.

**Commits:** `feat(search): EFU file lists`, `feat(app): file list editor and export`, `feat(search): file lists in the index`, `docs: file lists`

### Task 78: servers and network indexes (worktree `task78`; needs Task 71)

**Design points:**
- **HTTP server** for the system index (not only the library): `keel-daemon --web` gains a **Search all files** page and Everything's URL parameters (`search`/`s`/`q`, `offset`/`o`, `count`/`c`, `json`/`j`, `case`/`i`, `diacritics`/`m`, `wholeword`/`w`, `path`/`p`, `regex`/`r`, `prefix`, `suffix`, `ignore_punctuation`, `ignore_whitespace`, `sort` = name/path/date_modified/size, `ascending`, `path_column`, `size_column`, `date_modified_column`), so tools written for Everything's HTTP server work; bind address and port, logging, custom pages folder, default page, allow downloads switch; token auth plus optional Basic auth for those tools, TLS with a self-signed or user certificate.
- **ETP/FTP server**, compatible with Everything clients (FTP with the `SITE EVERYTHING` extension, link types, SUBST-style path mapping, bind interface, port, user and password, welcome message, logging, allow downloads), read-only; FTPS (explicit TLS) offered; plain FTP only after the review-focus warning.
- **ETP client:** "Connect to ETP server" adds a remote Everything (or Keel) as a search backend (`-connect user:pass@host:port`), results open through the existing FTP remote.
- **Network indexes** (Everything's Network Indexes tab and 1.5 Everything Server): paired Keel devices query each other's system index over keel-net (iroh) under a new grant **Search my files** (off by default, per device, revocable); results show the host (`network-index-host:`) and open through `node://`. A remote Everything Server is not supported (protocol not published); say so.

**Commits:** `feat(daemon): system search over HTTP with Everything parameters`, `feat(daemon): ETP server`, `feat(search): ETP client backend`, `feat(net): network indexes between devices`, `docs: servers and network indexes`

### Task 79: command line, SDK and protocol (worktree `task79`; needs Task 71)

**Design points:**
- **`keel es`** (also installed as `kes` on PATH, opt-in), compatible with `es.exe`: search syntax, match switches (`-case`, `-w`, `-p`, `-r`, `-diacritics`, prefix/suffix…), `-n`/`-max-results`, `-o`/`-offset`, `-path`, `-parent-path`, `-parent`, sort flags and DIR-style `/o`, `/ad`, `/a-d`, `/a<attrs>`, column switches (`-name`, `-path-column`, `-size`, `-dm`, `-dc`, `-da`, `-attributes`, `-run-count`, …, `-add-columns`), `-set-column-colors`/`-set-column-widths`, `-size-format`, `-date-format`, `-highlight`, export `-csv -efu -json -m3u -m3u8 -tsv -txt` and `-export-*` to a file, `-no-header`, `-utf8-bom`, `-count`, `-get-result-count`, `-get-total-size`, `-get-folder-size`, run count `-get-run-count`/`-set-run-count`/`-inc-run-count`, `-timeout`, `-save-db`, `-reindex`, `-no-result-error`, journal `-journal`, `-watch`, `-action-filter`, `-from-*`/`-to-*`, `-changed-today`; `-ipc1/2/3` accepted and ignored. A compatibility test runs the documented examples from Part 1 source E.
- **Window command line options** from Everything's list, mapped onto `keel`: `-search`/`-s`, `-path`, `-parent-path`, `-parent`, `-name-part`, `-stem`, `-extension`, `-filter`, `-bookmark`, `-home`, `-explore`, `-url`, sort variants with secondary/tertiary, `-details`, `-thumbnails`, `-columns`, `-select-*-result`, `-new-window`, `-new-tab`, `-toggle-window`, `-close`, `-startup`, `-restore-session`, `-exit`, `-restart`, `-config <ini>`, `-instance`, `-db`, `-read-only`, `-no-db`, `-load-delay`, `-reindex`, `-monitor-pause/resume/start/stop`, `-create-file-list`, `-connect`, `-install-service`/`-uninstall-service`, `-index-as-admin`, `-admin`, `-language`, `-safe-mode`. `keel [FOLDER] --search Q` scopes to FOLDER (fixes the audit's gap).
- **API and MCP:** `system.search`, `system.index.status`, `system.index.rebuild`, `system.journal`, `runs.get/set/inc`, `filelist.*`, `bookmarks.*`; MCP tools for each read op.
- **SDK:** a `keel-sdk` C ABI DLL with Everything's call shape (set search, match flags, max/offset, sort, request flags, query blocking and non-blocking, result count and per-result path, size, dates, attributes, run history), talking JSON-RPC to the running Keel or keel-daemon; headers, a C example and a Python `ctypes` example; Everything's own `Everything64.dll` is not imitated by name.
- **URL protocol** `keel:` (`keel:search?q=…`, `keel:open?path=…` opens a folder in Keel, never runs a file); `es:` registered only when the user ticks "Handle es: links" and Everything is not installed.
- **Shell and startup:** folder context menu **Search in Keel** (per-user registration), start on system startup, run in background, Start menu and desktop shortcuts (installer options), **portable mode** (a `keel.portable` file beside the executable keeps every setting, database and cache beside it; the audit found env overrides only), managed settings (`policy.toml` beside the executable or in ProgramData, settings it sets are locked in the UI), **safe mode** (no icon themes, no shell menu, no extensions).

**Commits:** `feat(cli): keel es`, `feat(cli): Everything window options`, `feat(api): system search ops`, `feat(sdk): C ABI SDK`, `feat(app): keel: URL protocol`, `feat(app): portable mode, policy and safe mode`, `docs: command line, SDK and protocol`
