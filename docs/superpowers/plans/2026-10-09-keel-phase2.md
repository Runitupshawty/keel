# Keel Phase 2 Implementation Plan: archives as folders + embedded terminal

> **For agentic workers:** implement one task per worktree, TDD, `cargo fmt` + `cargo clippy --all-targets -- -D warnings` + `cargo test --workspace` + `cargo check` for `x86_64-unknown-linux-gnu` and `aarch64-apple-darwin` before every commit. Read `docs/superpowers/specs/2026-10-08-keel-design.md` (2.1, 2.4, 2.9) and the Phase 1 plan's Global Constraints + Amendments first. Nothing in `keel-app` may use the `windows` crate; no IO on the UI thread; every OS-specific call behind `cfg(target_os)`.

**Goal:** open `.zip`, `.7z`, `.tar(.gz/.bz2/.xz/.zst)` and `.rar` as folders (nested too), extract / add-to-zip from the UI, preview files inside archives; a bottom terminal pane running PowerShell / cmd / WSL (Windows), zsh/bash (macOS), `$SHELL` (Linux) whose cwd follows the active pane.

**Spec:** `docs/superpowers/specs/2026-10-08-keel-design.md` sections 2.1 (archive provider, `!/` nesting), 2.4 (terminal), 2.9 (terminal shells per OS).

## Global constraints (in addition to Phase 1's)
- Archives are read-only except zip (add files) in Phase 2; rar/7z/tar never written.
- Extracting never overwrites silently: the same `Conflict` flow as copy.
- A corrupt or password-protected archive lists what it can and shows an error toast; never panics.
- Archive entries larger than 1 GiB are not materialised for preview (show `TooLarge`).
- Terminal input/output never touches the UI thread except painting the grid: pty reads run on a thread, the grid is behind a `parking_lot::Mutex`, the UI repaints on a channel notification.
- CI matrix must stay green on all three OSes; rar tests use a committed 2 KiB fixture generated with WinRAR (`C:\Program Files\WinRAR\Rar.exe a -ep fixture.rar a.txt sub/b.txt`).

## Review focus
1. Zip-slip: entry names with `..`, absolute paths, or drive letters must never escape the extraction target (test with a crafted zip).
2. Nested archives: `zip inside tar inside zip` lists and previews; the materialised cache is bounded (LRU by bytes, 2 GiB) and keyed by (outer path, mtime, size, inner path).
3. A 10,000-entry zip lists in < 200 ms and does not read entry bodies on `list`.
4. Terminal: a process that writes 50 MB in one burst does not freeze the UI; resize keeps the grid consistent; closing the pane kills the child; Ctrl+C goes to the child, not to Keel's copy action, when the terminal has focus.
5. WSL absent, `pwsh` absent, `$SHELL` unset: the shell picker still offers something that exists.

### Task 11: `keel-vfs` archive provider + nested paths (worktree `task11`)

**Files:** `crates/keel-vfs/src/{archive/mod.rs, archive/zip.rs, archive/sevenz.rs, archive/tar.rs, archive/rar.rs, archive/cache.rs}`, modify `path.rs` (nesting), `router.rs` (resolve `!/`), `ops.rs` (`extract`, `add_to_zip`), tests in `crates/keel-vfs/tests/archive.rs`, fixtures in `crates/keel-vfs/tests/fixtures/` (generated zip/tar/7z at test time with the crates; committed `sample.rar`).

**Deps (workspace):** `zip = "2"` (deflate, bzip2, zstd features), `sevenz-rust = "0.6"`, `tar = "0.4"`, `flate2`, `bzip2`, `xz2` or `liblzma`, `zstd`, `unrar = "0.5"` (bundles libunrar source; builds with cc on all three OSes; confirm it compiles on Linux/macOS via `cargo check` targets and in CI).

**Interfaces (Produces):**
```rust
// path.rs — additions
impl VPath {
    /// "file:///D:/x.zip!/dir/a.txt" => outer = file:///D:/x.zip, inner = "dir/a.txt". Multiple `!/` allowed.
    pub fn split_archive(&self) -> Option<(VPath /*outer*/, String /*inner, '/'-separated, no leading '/'*/)>;
    pub fn join_archive(outer: &VPath, inner: &str) -> VPath;
    pub fn is_archive_name(name: &str) -> bool;       // by extension: zip jar 7z tar tgz tar.gz tar.bz2 tar.xz tar.zst rar
}
// archive/mod.rs
pub struct ArchiveProvider { cache: Arc<MaterialiseCache> }
impl Provider for ArchiveProvider { fn scheme(&self) -> &'static str { "archive" } ... }
// Router: provider_for(p) returns ArchiveProvider when p.split_archive().is_some(); the archive provider
// asks the router for the OUTER path's provider and calls local_copy on it (so sftp://.../x.zip works later).
pub trait ArchiveReader: Send {
    fn entries(&mut self) -> Result<Vec<ArchiveEntry>>;                 // metadata only, never bodies
    fn read(&mut self, inner: &str) -> Result<Box<dyn Read + Send>>;   // one entry body, streaming
}
pub struct ArchiveEntry { pub inner: String, pub is_dir: bool, pub size: u64, pub modified: Option<SystemTime>, pub encrypted: bool }
pub fn open_archive(local: &Path) -> Result<Box<dyn ArchiveReader>>; // dispatch by magic bytes, then extension
// archive/cache.rs
pub struct MaterialiseCache { root: PathBuf /* <cache dir>/archives */, budget: u64 /* 2 GiB */ }
impl MaterialiseCache { pub fn get_or_extract(&self, key: &CacheKey, extract: impl FnOnce(&Path) -> Result<()>) -> Result<PathBuf>; pub fn evict_to_budget(&self); }
// ops.rs — additions
pub fn extract(archive: &VPath, entries: &[String] /* empty = all */, dst_dir: &Path, on_conflict: Conflict,
               progress: &dyn Fn(Progress), cancel: &AtomicBool, router: &Router) -> Result<()>;   // zip-slip safe
pub fn add_to_zip(zip_path: &Path, src: &[PathBuf], inner_dir: &str, progress: &dyn Fn(Progress), cancel: &AtomicBool) -> Result<()>; // creates the zip if missing; rewrites atomically via temp + rename
```

**Steps:** (1) `split_archive`/`join_archive` tests incl. nested + Windows paths; (2) zip reader (list without reading bodies; `enclosed_name()` for slip safety; encrypted flag); (3) tar family via `tar` + decompressors by magic; (4) 7z via `sevenz-rust`; (5) rar via `unrar` crate (list + extract single entry to a temp file for `read`); (6) `open_archive` by magic bytes (PK\x03\x04, 7z\xBC\xAF\x27\x1C, Rar!\x1A\x07, gzip 1F8B, bzip2 BZh, xz FD377A585A00, zstd 28B52FFD, else tar by ustar at 257); (7) `ArchiveProvider::list/stat/read/local_copy` with the router for the outer path and the cache for nested archives; (8) `extract` with slip test + conflict flow + progress; (9) `add_to_zip` atomic rewrite test; (10) perf test `#[ignore]` 10k-entry zip < 200 ms; (11) Linux/macOS `cargo check` + clippy; commit `feat(vfs): archives as folders (zip/7z/tar/rar), nested paths, extract and add-to-zip`.

### Task 12: `keel-term` + terminal pane (worktree `task12`)

**Files:** `crates/keel-term/{Cargo.toml, src/lib.rs, src/session.rs, src/shells.rs, src/grid.rs}`, `crates/keel-app/src/term_pane.rs`, modify `app.rs` (bottom panel), `state.rs` (toggle + cwd follow), `keys.rs` (Ctrl+` toggle; focus routing), `settings.rs` (`terminal_shell`, `terminal_follow_cwd`, `terminal_height`).

**Deps:** `portable-pty = "0.9"`, `vt100 = "0.15"` (or `alacritty_terminal` if vt100 lacks what is needed; prefer vt100 for size).

**Interfaces (Produces):**
```rust
// keel-term
#[derive(Clone, Debug, PartialEq)] pub struct Shell { pub label: String, pub program: PathBuf, pub args: Vec<String>, pub kind: ShellKind }
#[derive(Clone, Copy, Debug, PartialEq)] pub enum ShellKind { PowerShell, Cmd, Wsl, Posix }
pub fn available_shells() -> Vec<Shell>;   // Windows: pwsh.exe, powershell.exe, cmd.exe, `wsl.exe -d <distro>` for each `wsl -l -q` line; macOS: $SHELL, /bin/zsh, /bin/bash; Linux: $SHELL, /bin/bash, /bin/sh. Only existing programs. Never empty: falls back to cmd.exe / /bin/sh.
pub struct Session { /* pty master, child, reader thread, grid */ }
impl Session {
    pub fn spawn(shell: &Shell, cwd: &Path, cols: u16, rows: u16, notify: Arc<dyn Fn() + Send + Sync>) -> Result<Session>;
    pub fn write(&self, bytes: &[u8]) -> Result<()>;
    pub fn resize(&self, cols: u16, rows: u16) -> Result<()>;
    pub fn grid(&self) -> parking_lot::MutexGuard<'_, vt100::Parser>;   // screen() for cells, cursor, title
    pub fn cd(&self, dir: &Path);        // sends an OS-appropriate `cd` line: PowerShell `Set-Location -LiteralPath '...'`, cmd `cd /d "..."`, WSL `cd "$(wslpath '...')"`, posix `cd '...'` — only when the shell is idle (no running child: heuristic = last output ended with a prompt-like char within 300 ms of input; document the heuristic)
    pub fn kill(&mut self);
    pub fn is_alive(&self) -> bool;
}
pub fn wslpath(win: &Path) -> String;   // D:\Work\x => /mnt/d/Work/x (pure string transform; test)
```

**App:** bottom `TopBottomPanel` (resizable, default 220 px, remembered), shell picker dropdown + "+" to restart, Ctrl+` toggles, "Follow pane" checkbox (on by default) sends `cd` when the active pane navigates, `Open terminal here` context item focuses the pane and `cd`s. Painting: monospace grid from `vt100::Screen` cells with fg/bg colours and bold, cursor block, scrollback via vt100's scrollback (set 10,000 lines), mouse wheel scrolls. Input: when the terminal has focus, all key events go to the pty (translate egui keys to VT sequences: arrows, Home/End, PgUp/PgDn, Backspace, Delete, Tab, Enter, Esc, Ctrl+letters as control bytes, Ctrl+Shift+C/V copy/paste), and Keel's own shortcuts are suppressed except Ctrl+` and F6/Escape to leave the terminal. Child exit shows "[process exited] press Enter to restart".

**Steps:** (1) `available_shells` + `wslpath` tests; (2) `Session::spawn` echo test (`cmd /c echo hi` or `sh -c 'echo hi'`) asserts "hi" appears in the grid within 2 s; (3) burst test: `sh -c 'yes | head -c 50000000'` / PowerShell `'x'*50000000` must not block `grid()` for > 50 ms (reader thread parses, UI just locks); (4) resize test; (5) term_pane painting + input routing; (6) cwd follow + Open terminal here; (7) settings; (8) manual check on Windows with pwsh, cmd, and (if installed) WSL; commit `feat(term): embedded terminal pane with PowerShell/cmd/WSL/posix shells`.

### Task 13: app integration of archives (worktree `task13`, after 11 + 12 merge)

**Files:** modify `crates/keel-app/src/{state.rs, tab.rs, view_details.rs, view_grid.rs, sidebar.rs, jobs.rs, dialogs.rs, preview_panel.rs, icons.rs}`.

- Navigating into an archive file (Enter/double-click on `*.zip` etc.) opens it as a folder (breadcrumb shows `x.zip › dir`); Up from the archive root returns to the containing folder; Back/Forward work. Entries show the archive icon; encrypted entries show a lock and refuse preview with a toast.
- Context menu on an archive: `Extract here`, `Extract to folder "<name>"`, `Extract to…` (folder picker via `rfd`); on files/folders: `Add to <name>.zip` and `Compress to zip…`. All run as jobs with progress + conflict dialog.
- Inside an archive: copy (Ctrl+C) materialises on paste (job); delete/rename/new are refused with a toast ("archives are read-only in this version"); drag out of an archive = extract.
- Sidebar section "Open archives" listing archives currently open in any tab.
- Preview panel works inside archives (via `local_copy`); thumbnails too (bounded by the 1 GiB rule).
- Session restore re-opens archive tabs if the archive still exists.
- Tests: open fixture zip in a tab → entries listed; Up from root returns to the folder; extract job lands files; refusal toasts.
- Commit `feat(app): browse archives as folders, extract, add to zip`.
